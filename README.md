# @opsflow/orchestrator

OpsFlow control plane — capability registry + deployment/canary/shadow governance, and (incrementally) the cohesive turn-owner that validates the `@opsflow/contracts` `AgentResult` envelope.

Part of the OpsFlow multi-repo set. Depends on `@opsflow/contracts` + `@opsflow/platform`.

## Dev
```
npm install   # resolves @opsflow/* via the file: links (see opsflow-devspace for the workspace)
npm run build
npm test
```
